# Textures urbaines

These layers are rendered by `tools/blender/make_buildings.py`. Each one is real geometry (windows, sills, shutters, balconies, shop windows, road markings) placed over [Poly Haven](https://polyhaven.com) photos licensed **CC0** (public domain).

Download the sources with `python3 tools/blender/fetch_urban_sources.py`. That script holds the list of assets used: brick_wall_001, painted_plaster_wall, brown_planks_07, plaster_grey_04, rectangular_facade_tiles, corrugated_iron_02, clay_roof_tiles_02, roof_slates_02, box_profile_metal_sheet, gravel_concrete, asphalt_02, square_concrete_pavers, concrete_wall_008 and leafy_grass.

The files are listed in the same order as the texture array (`urban::LAYER_NAMES`).
